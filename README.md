# QYS RTOS

> 面向嵌入式开发者的 Windows 桌面工作台，支持 Zephyr 和基于 PlatformIO 的普通单片机工程。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 项目简介

QYS RTOS 在同一个窗口提供 **Zephyr 工程** 和 **普通单片机** 两个工作台。Zephyr 工程由 west 和 Zephyr SDK 构建、烧录。普通单片机工程由 PlatformIO Core 管理工具链、构建和烧录。

软件希望解决的问题很简单：开发者不必在编辑器、PowerShell、串口工具和烧录工具之间来回切换，就可以在同一个项目界面中完成“打开工程 → 修改代码 → 编译 → 烧录 → 查看串口日志”的基本流程。

## 主要功能

- **Zephyr 工程管理**：创建模板工程、打开已有工程、浏览和编辑源码。
- **编译与烧录**：调用当前工作区的 west 和目标板工具链，保留按开发板区分的构建目录。
- **普通单片机工作台**可按需下载板卡支持包，新建或打开 PlatformIO 工程，按选定的构建环境编译、烧录和监视串口。
- **串口监视**：查看启动日志、应用输出和编译/烧录过程中的端口信息。
- **设备树辅助**：查看最近一次构建生成的设备树，并生成 overlay 配置预览。
- **环境引导**：检查 Python、Git、west、Zephyr 工作区和 SDK，辅助安装缺失的前置工具。
- **AI Agent**：通过兼容 Chat Completions 和工具调用的模型，解释工程、修改文件和辅助排错；API 密钥在本机加密保存。
- **Windows 原生桌面体验**：基于 PySide6，适合希望使用图形界面进行嵌入式开发的用户。

## 快速开始

### 下载安装包

从 [GitHub Releases](https://github.com/Luarius/QYS-RTOS/releases) 下载已发布版本的 `QYS-RTOS-Setup.exe`，安装后启动 QYS RTOS。若发布页暂无附件，安装包仍待上传。软件安装包不包含 Zephyr SDK；首次使用请打开右上角的“环境引导”，或者在“环境设置”中选择已有的 Zephyr 工作区、west 和 SDK。

### 从源码运行

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_app.py
```

构建 Windows 安装包需要额外安装 `requirements-build.txt` 中的依赖。完整使用说明、AI Agent 注意事项和设备树操作说明见下文。

### 构建安装包

在 Windows 上安装 [NSIS](https://nsis.sourceforge.io/Download)，在项目根目录执行以下命令；请将 NSIS 路径改为电脑上的实际位置：

```powershell
python -m pip install -r requirements-build.txt
.\scripts\build.ps1 -DistRoot .\release\QYS-RTOS-1.2-build
python .\scripts\create_installer.py `
  ".\release\QYS-RTOS-1.2-build\QYS RTOS" `
  ".\release\QYS-RTOS-1.2-build\installer\QYS-RTOS-1.2-Setup.exe" `
  --compiler "C:\Program Files (x86)\NSIS\makensis.exe"
```

构建脚本不会覆盖已有的输出目录。执行测试可运行 `python -m unittest discover -s tests -v`；没有本机 Zephyr 环境时，依赖实际环境的测试会跳过。

QYS RTOS 是一个 Windows 桌面程序，用于打开和创建 Zephyr 工程、编辑源文件、编译、烧录、运行 PowerShell 命令和查看串口输出。

## 安装与首次使用

运行 `QYS-RTOS-Setup.exe` 并按提示安装，然后从开始菜单或桌面打开 QYS RTOS。安装软件本身不包含 Zephyr SDK；另一台电脑首次使用时，打开右上角的 **环境引导**，按向导检查前置工具，选择一个新的空工作区并启动联网安装。也可以通过 **环境设置** 选择电脑上已有的 Zephyr 工作区、west 和 SDK。

环境引导默认安装 ARM 和 RISC-V 工具链，也可以选择全部架构。源码、模块和 SDK 的下载可能需要较长时间和较多磁盘空间。向导会先检查 GitHub 连接；如果提示本机代理不可用，请检查代理程序和 Git 代理设置，再重新尝试。向导不会自动修改代理设置。

Windows 上优先使用 Python 3.12。安装向导会检测常用前置工具，并可通过 **安装缺失的前置工具** 调用 winget。某些开发板还需要额外的下载器、驱动或辅助工具，请留意向导中的检测结果。

安装过程中如遇失败或停止，向导会保留已经下载的部分文件，并显示出错命令；要重新开始，请选择一个新的空目录，或自行检查并整理之前的目录。向导不支持自动续传安装流程。

## 使用工程

1. 点击 **新建工程**，选择 Hello World 或 Blinky 模板；也可点击 **打开工程**，选择已有 Zephyr 应用文件夹。
2. 从左侧文件树打开和编辑文件，`Ctrl+S` 保存。
3. 在顶部搜索并选择完整的开发板目标；需要串口烧录时选择对应端口。开发板列表来自当前工作区的 west。
4. 点击 **编译** 查看构建输出，或点击 **烧录**：软件会先保存修改并编译，成功后再执行烧录。构建产物默认位于工程的 `build_qys` 文件夹，并按开发板分别保存。
5. 下方 **PowerShell** 支持输入普通命令；**串口监视** 用于收发串口数据。烧录开始前，QYS RTOS 会关闭自己打开的串口监视以释放端口。

烧录器由 Zephyr 构建结果指定。ESP32 和 stm32flash 使用顶部选择的串口；SWD/J-Link 等烧录器通常使用自己的设备发现方式，必要参数可填在底部 **附加参数**。实际支持情况取决于开发板对应的 SDK、下载器驱动和工具是否已安装。

串口监视中的提示会显示所选端口的信息和当前构建的 `zephyr,console` 路由。如果没有输出，请核对端口、波特率、接线和固件中的控制台配置。设备树和电脑端的端口信息不能单独证明二者接到了同一个物理接口。

## 普通单片机工作台

1. 点击窗口顶部的 **普通单片机**。软件会检测已有的 PlatformIO Core。也可以在 Core 菜单手动选择 `pio.exe`，或使用已安装的 Python 3.12 及以上版本联网安装 Core。
2. 打开 **板卡扩展**，选中型号后点击 **下载支持包**，在输出区查看工具链和烧录器的下载进度。
3. 点击 **新建普通工程**，选择板型和新目录。也可以打开已有的 `platformio.ini` 工程，在 **构建环境** 中选择目标。已有工程可使用其 PlatformIO 配置支持的板卡。
4. 点击 **编译** 生成固件。点击 **烧录普通板卡**，确认板型、环境和目标后写入。使用串口烧录时先选 COM 口，使用 ST-Link 时接好 SWD。

| 板卡模板 | 示例 | 烧录方式 |
| --- | --- | --- |
| ESP32-S3-DevKitC-1 N8 | Arduino 串口日志，115200 波特率 | esptool 串口 |
| STM32F103C8T6 Blue Pill | STM32Cube HAL 翻转 PC13 | ST-Link / SWD |
| STC89C52RC | SDCC 翻转 P1.0 | stcgal 串口，按提示给目标板重新上电 |

1.2 的安装目录、快捷方式和设置独立命名。新版首次启动时可读取旧版的 Zephyr 设置，并将之后的更改写入新版设置目录。

## 使用 AI Agent

1. 打开一个 Zephyr 工程，在右侧 **AI Agent** 面板中点击 **模型设置**。如果面板隐藏，可点击顶部 **AI Agent** 重新打开。
2. 选择 DeepSeek、通义千问或自定义兼容接口，填写服务商提供的接口地址、模型名称和 API 密钥，点击保存。服务地址、模型名称和密钥应与服务商账号及地区一致。密钥和接口地址由当前 Windows 用户的系统保护功能加密保存，不需要发送给他人。
3. 在面板中输入任务，例如“解释当前工程”或“修改 LED 闪烁节奏”，点击 **发送任务**。Agent 会根据任务读取当前工程中的相关文本文件，直接修改文件前会保存原内容；它不会执行任意终端命令或自行烧录。
4. 要协助排查编译问题，先通过顶部 **编译** 按钮编译，再勾选 **附带最近的编译输出** 并向 Agent 描述问题。只有当前工程最近一次编译输出会被附带。
5. 修改后可以点击 **恢复上次修改** 逐次恢复，也可以点击 **查看备份** 查找原文件备份。若文件在 Agent 修改后又被更改，自动恢复会停止，避免覆盖更新内容。

发送任务时，任务内容和 Agent 读取到的工程文件会发送给所选模型服务；勾选编译输出时也会发送对应日志。软件会拦截一些明显的密钥内容，但无法识别所有敏感信息，请自行检查。云模型调用可能产生费用。Agent 只支持提供兼容 Chat Completions 和工具调用接口的模型，实际功能取决于服务商。模型可能生成错误代码；构建脚本也可能在编译时执行命令，请检查修改后再编译和烧录。

为保护未保存的内容，编辑器有未保存修改时请先保存，再使用 Agent。Agent 工作期间工程编辑与编译、烧录暂不可用；需要中止时点击 **停止**。备份位于当前 Windows 用户的 QYS RTOS 配置目录，不随工程一起复制。

## 查看和修改设备树

设备树描述开发板的设备及连接。先打开工程、选择开发板并点击 **编译**，再打开 **设备树** 标签。页面显示该工程上一次编译生成的设备树；修改源文件后，需要重新编译和刷新才能看到新结果。

在左侧按节点名称、标签或路径搜索并选择节点，右侧会显示属性。要启用或禁用节点，选择状态并点击 **生成配置预览**，检查预览后选择工程中的 overlay 文件，再点击 **加入工程文件**。配置先进入代码编辑器，检查后按 `Ctrl+S` 保存，再重新编译。点击 **编译** 或 **烧录** 也会先保存全部已修改文件。其他 overlay 可能覆盖这个设置，请在重新编译后的设备树中核对。

软件只列出上次构建记录中能确认属于当前工程的 overlay。如果没有可选文件，可以点击 **复制配置**，手动加入实际参与构建的 overlay。切换工程、开发板或构建目录后，请重新刷新设备树。

拖动设备树与下方输出面板之间的分隔条，可以调整两个区域的大小。

## 本机源代码运行

开发者可在项目目录创建虚拟环境，安装 `requirements.txt` 后执行 `python run_app.py`。构建依赖见 `requirements-build.txt`。软件设置保存在当前用户的应用数据目录，卸载软件不会自动删除 Zephyr 工作区、工程或这些设置。
